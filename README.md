# PG Life

A fully responsive website where users can explore and book PGs (Paying Guest accommodations) by viewing the room environment, available facilities, and reviews.

---

## Built With

This project was built using the following technologies:

- **HTML**
- **CSS**
- **JavaScript**
- **Bootstrap**
- **PHP**
- **MySQL**
- **React.js**

---

## Features

PG Life website offers a user-friendly experience with the following features:

- **Header Section**: Includes the logo, along with Sign-up and Login modals.
- **Search Bar**: Allows users to search for rental apartments by cities.
- **Properties List**: Displays a list of properties available in various cities.
- **Filter Options**: Users can filter PGs based on different criteria.
- **Dashboard Page**: An interactive page for managing user-specific activities.
- **Footer Section**: Contains essential links and information.

## Installation

Follow these steps to set up the project locally:

### 1. Fork and Clone the Repository

Fork the repository on GitHub and then clone it to your local machine:

```bash
git clone https://github.com/avinishofficial/PG-LIFE
```

### 2. Navigate to the Project Directory

```bash
cd PG-Life.github.io
```

### 3. Connect to the Database

1. Open **phpMyAdmin** in your browser.
2. Click on the **Databases** tab.
3. Create a new database named `pglife`.
4. Go to the **Import** tab.
5. Click on **Browse File** and select the `pglife.sql` file from this repository.
6. Click **Go** to import the database structure and data.

---

## Usage

Once the database setup is complete, ensure the project files are placed in your local server (e.g., XAMPP or WAMP). Access the website by navigating to `http://localhost/PG-Life.github.io/` in your browser.
